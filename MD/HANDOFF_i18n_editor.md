# 12cut 다국어(번역) 작업 공유 — 외주 전달용

> 작성: 2026-06-02 · 대상: 공통 레이어 담당 외주 개발자

## 한 줄 요약
스토리 편집기와 고도 시스템 UI를 **영어·일본어·중국어**로 번역했고, 그 과정에서 **공유 파일 `12cutEditor.html`을 직접 수정**했습니다. 덮어쓰기 사고 방지를 위해 공유드립니다.

---

## 1. 번역이 동작하는 구조
- 상품 페이지 / 고도 시스템 UI / **스토리 편집기**가 **모두 `/dobuddy/files/{언어}.html` 사전 파일 하나를 공유**합니다.
- 편집기는 켜질 때 이 사전을 불러와 `$t('한국어원문')` 자리에 번역을 끼워 넣습니다.
- **사전에 키가 없으면 한국어 그대로** 노출됩니다.
- 즉, 번역 = **사전 파일에 "한국어 원문 → 번역" 키 추가**.

## 2. 제가 한 작업

### (A) 사전 파일 보강 — `/dobuddy/files/en.html · ja.html · zh.html`
- 편집기/시스템 UI에서 비어있던 기능성 문구를 채웠습니다. (총 키 **323 → 362**)
- ⚠️ **브라운더스트2 캐릭터 고유명(프로즌퀸 등)은 일부러 손대지 않았습니다.**

### (B) `12cutEditor.html` 직접 수정 — 공유 파일이라 알려드립니다
일부 알림/토스트 문구가 `$t()`로 감싸져 있지 않아 번역이 안 됐습니다. 아래 **7곳을 `$t()`로 감쌌습니다.** (로직 변경 없음, 번역만 적용)

| 위치 | 한국어 문구 |
|---|---|
| 사진 삭제 확인 | 사진을 삭제하시겠습니까? |
| 트리밍 완료 확인 | 사진 트리밍 완료하셨나요? |
| 저장 실패 | 저장에 실패했습니다. |
| 이미지 크기 경고 | (847)px 미만인 이미지는… |
| 토스트 | 12컷 선택 / 완료해주세요 |
| 토스트 | 순서 선택 / 완료해주세요 |
| 페이지 이탈 경고 | 편집중인 스토리가 삭제됩니다. |

- 파일 크기: 27,375B → 27,405B (7곳 `$t(...)` 래핑만 증가)

---

## 3. 부탁드리는 것 (중요)
1. **`12cutEditor.html`을 로컬 사본으로 덮어쓰지 말아주세요.** 위 7곳 래핑이 사라지면 알림창이 다시 한국어로 나옵니다.
2. 혹시 그새 편집기를 수정하셨다면, 변경분을 합쳐야 하니 **알려주세요.** (제가 받은 시점: 6/2 오전)
3. 가능하시면 **이 7곳 래핑을 외주 측 원본 코드에도 영구 반영**해 주시면, 앞으로 양쪽이 덮어쓸 일이 없어 가장 깔끔합니다.

## 4. 앞으로 (제안)
새 문구를 추가하실 때 **`$t('한국어')`로 감싸서** 넣어주시면, 저희가 사전 파일에만 번역을 추가하면 됩니다 — **편집기 코드는 다시 안 건드려도 됩니다.**
